# Code of Conduct

## Our Standards

This project aims to be a respectful and constructive community.

- Be professional and considerate in discussions and reviews.
- Focus criticism on ideas, code, and behavior, not on people.
- Assume good intent, ask clarifying questions, and avoid hostile language.
- Respect differences in background, experience, and viewpoint.

## Unacceptable Behavior

- Harassment, personal attacks, intimidation, or discrimination.
- Insults, trolling, repeated bad-faith arguments, or deliberate disruption.
- Publishing private information without explicit permission.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, discussions, and other official communication channels.
